# Receptboken

En enkel svensk Android-app som fungerar helt offline.

## Funktioner

- Tryck på en maträtt för ingredienser och steg
- Sök bland namn, kategorier och ingredienser
- Favoritmarkera recept
- Lägg till, redigera och ta bort egna recept
- Fem färdiga svenska recept
- All data sparas lokalt på telefonen

## Bygg APK

Öppna projektet i Android Studio och välj **Build > Build APK(s)**. APK-filen hamnar i `app/build/outputs/apk/debug/`.
